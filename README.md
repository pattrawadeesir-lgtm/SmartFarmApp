# 🌱 Smart Farm IoT Application

แอปพลิเคชัน Smart Farm สำหรับตรวจสอบและควบคุมระบบฟาร์มแบบ Real-time โดยเชื่อมต่อ **ESP32 กับ Mobile Application ผ่าน MQTT**

## ✨ Features
- 🌡️ ตรวจสอบ Temperature และ Humidity
- 💡 ตรวจสอบระดับแสง
- 🌱 ตรวจสอบ Soil Moisture
- 🤖 ระบบ AUTO / MANUAL
- 🌀 ควบคุม Fan
- 💡 ควบคุม Farm Light
- 🚿 ควบคุม Water Pump
- 🔔 ระบบแจ้งเตือนสถานะอุปกรณ์
- 📊 หน้า Analytics

## ⚙️ Automatic Control
- Temperature ≥ 30°C → Fan ON
- Light ADC > 1900 → Farm Light ON
- Soil Moisture 0–29% → Water Pump ON

## 🛠️ Technology
React Native • Expo • TypeScript • ESP32 • MQTT • Wokwi • PlatformIO
